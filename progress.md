## Implemented behaviour
- ASP.NET Core MVC Web and Worker hosts with Domain, Application and Infrastructure boundaries.
- ASP.NET Core Identity with GUID users/roles, local registration/login/logout and secure framework cookies.
- Owner-filtered create/list/open/rename/archive/restore/delete project actions; SQL `rowversion` concurrency token and a creator-facing conflict outcome.
- Private originals outside `wwwroot`, generated opaque keys, canonical traversal checks, streamed SHA-256 hashing, bounded upload/project counts and sizes, and cleanup on failed persistence/project deletion.
- Byte-signature inspection plus bounded ffprobe decode/stream/metadata validation for supported uploads; unrecognised, corrupt and streamless input is rejected.
- Owner attestation is labelled honestly. Permission withdrawal blocks playback. Authorised media responses support range requests.
- Responsive editorial UI tokens, exact tagline, Record/Shape/Make/Export navigation, real source players and disabled future stages with reasons.
- Modern visual system inspired by the user-provided Thungela Career Pathways reference: self-hosted Jost typography, warm near-black/amber palette, strong editorial hero, rounded layered cards, clearer account screens and responsive navigation. The product retains its own identity and content.
- Progressive microphone capture with refusal/unsupported upload fallback, five-minute cap, preview, unsaved-navigation warning and direct private “Use this recording” persistence. Genuine `.weba`/WebM audio is accepted only after its EBML container signature passes inspection.
- Recording UX now has a pulsing microphone indicator, elapsed timer, explicit disabled/grey recording button, review state, adjacent recording-specific permission confirmation and visible save failure text. Successful saves are confirmed in Sources and expose a direct “Continue to Shape” action.
- Manual Shape workflow: immutable reviewed transcript revisions with source timing/playback, source-backed scenes, reorder by new revision and exact snapshot approval.
- Make workflow: declared equipment, people, locations, time and budget resources with availability state and visible scene/coverage status.
- Export workflow: readiness reasons, deduplicated durable queue, SQL Server `UPDLOCK`/`READPAST` atomic claims, expiring attempt leases, bounded retries, stale-attempt rejection and worker recovery.
- Real FFmpeg pipeline using `ProcessStartInfo.ArgumentList` with shell execution disabled: trims original audio, combines real visuals, emits portrait H.264/AAC MP4 and remapped SRT, then ffprobes streams/dimensions/duration before publishing immutable artifacts.
- Web and Worker load the same studio graph (`IncludeStudio`), so the Worker's readiness check matches what the creator saw, including language reviews, credits and shots.
- Scenes can be edited or removed; each change creates a new immutable revision and needs fresh approval. Move buttons are disabled at the ends of the list; each scene card plays its exact source range.
- Quotation fidelity: a scene marked “From your recording” must link to a reviewed transcript of the same audio, sit inside its reviewed range, and repeat its words (whitespace-normalised). Enforced on save and again in readiness.
- Protected expressions (comma/newline separated) that are spoken in a quoted scene must appear in its caption and translation, otherwise the final export is blocked.
- Optional second caption language: per-scene translated captions are part of the snapshot hash, shown as Draft until a language review is recorded for that exact snapshot, and exported as a separate SRT.
- Credits: creator-written roles/names, optionally linked to a source, approved as an exact set (hash). Final export requires approved current credits; a 5-second credits card with the tagline is rendered at the end and counted in the 60–90 second rule. Artifacts record the credits hash and become stale when credits change.
- Shot list in Make: owner-written shots or labelled suggestions (one per unplanned scene) that use only available declared resources. Shots are Planned, Captured (linked to a permitted uploaded image/video) or Dropped; a planned shot blocks the final, and shots whose resources became unavailable are flagged for replanning.
- Captions and the credits card are burned into rendered video with FFmpeg `drawtext` reading text files with expansion disabled from the render's working directory, so brackets, apostrophes, colons, percent signs and backslashes stay literal. The bundled Jost font is copied beside Web and Worker; `Media:BurnInCaptions` and `Media:CaptionFontFile` are configurable. All segments are normalised to 48 kHz stereo AAC before concatenation.
- Withdrawing a source cancels queued/running exports for the project, blocks downloads of artifacts that used it, and blocks preservation archives of the affected story.
- Export shows the time from project creation to the first approved cut, supporting the pilot measure in project-description.md.
- 2026-11-10 UI refresh (user-chosen bold, African-inspired direction): earth-tone tokens (sand, terracotta, ochre, indigo, malachite) with an abstract geometric pattern band and emblem; a studio header on every stage with progress, per-stage checklist and a computed “Next step” card (`StudioProgressCalculator`, derived only from stored state); numbered steps on each stage with advanced/AI sections folded into panels; a fixed bottom stage bar on phones; seconds-based timing with “Set start/end from player” and “Play this stretch”; choosing saved words auto-fills the recording, range and quote; an in-page film player; checklist items link to the fix; a real landing page replaces the template Home page; signed-in users go straight to their stories.

## Decisions

| Decision | Reason |
| --- | --- |
| OpenAI Codex is the development assistant; AGENTS.md is the entry point. | Latest explicit user instruction. |
| MVC, Razor, EF Core/SQL Server and modular Domain/Application/Infrastructure boundaries. | Architecture specification. |
| Pin .NET SDK 10.0.403 and EF Core/Identity/EF CLI 10.0.11. | Versions were actually inspected, installed/restored and built together. |
| Keep AI Manual by default and leave model IDs empty in committed settings. | Live configuration and credentials remain opt-in and outside Git; missing Live configuration must fail rather than fabricate output. |
| Local User Secrets select Live with `gpt-6-luna` for structured story assistance and `gpt-transcribe` for completed recordings. | Official OpenAI documentation inspected 2026-11-09; one bounded story call succeeded on 2026-11-10. Secret values remain outside Git. |
| Store Identity framework join/claim tables with their supported key shapes; application tables use GUID primary keys. | Security-compatible exception documented by architecture.md. |
| Final export requires approved credits and counts a fixed 5-second credits card in the 60–90 second rule. | product.md requires approved credits before export; a fixed card keeps the duration rule predictable. |
| Shots link to scenes by title rather than scene ID. | Scene IDs change with every immutable revision; titles survive reorder/edit. Renaming a scene detaches its shots, which then stop blocking. |
| Burn captions with `drawtext` text files instead of libass/SRT burn-in. | SRT/ASS burn-in interprets `{...}` override tags; text files with expansion disabled render caption text literally and need no path escaping. |
